# Platform Status

## iOS

- Native rendering with SceneKit.
- Supports remote URLs, local files, bundled assets, pan, pinch zoom, initial yaw/pitch, and events.

## Android

- Native rendering with SceneView/Filament.
- Supports remote URLs, local files, Android content URIs, bundled assets, pan, pinch zoom, initial yaw/pitch/fov, and events.
- Recent initialization fixes ensure `initialFov` is respected on first load.
